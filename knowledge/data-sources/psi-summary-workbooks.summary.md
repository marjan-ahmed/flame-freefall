The spreadsheets held beside the PSI experimental tables, described by what
their sheets actually contain, because the file names mislead.

- **SAFFIRE MergeResult workbooks** hold only records of image files (names,
  sizes, received / corrupt flags), no combustion data at all. The SAFFIRE
  results are in the SAFFIRE reports.
- **Combined SAMER Results** (43 sheets) is the working results file behind
  SAME and SAME-R: per-material sheets, reduced data, ground tests, and
  sheets behind papers.
- **CFI data summary**: its DATA sheet holds the per-test CFI results
  (droplet diameters, burning-rate constants) that the experimental table
  lacks.
- **Other matrices**: the BASS as-run matrix, an ACME downlink data log, and
  a SAME-R thermal precipitator map.
- One matrix workbook is never opened because it contains account
  credentials.
