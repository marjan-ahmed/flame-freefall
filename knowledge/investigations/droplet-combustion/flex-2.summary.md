This entry is FLEX-2's Science Requirements Document (March 15, 2010): the
plan for the droplet experiments, written before the flights. It contains no
flight results.

- **Planned categories:** pure fuels (n-decane, ethanol), fuel mixtures
  including jet- and gasoline-like surrogates, slow convective flows, and
  binary droplet arrays.
- **Planned envelope:** oxygen mole fraction 0.17, 0.21, 0.25, and 0.30;
  pressure 0.5 to 3.0 atm; droplets 1.5 to 5.0 mm; flow 0.1 to 5 cm/s; O2/N2
  and O2/He mixtures.
- **Planned test counts:** 100 each for quiescent n-decane and ethanol, 50
  each with flow.
- **Open question:** which fuels actually flew is not established by this
  source; the PSI FLEX-2 table names some fuels that differ from this plan.
